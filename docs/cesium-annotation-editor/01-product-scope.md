# 01 Product Scope

## 目标

实现一个轻量 Cesium 标注编辑插件，让业务系统可以在 Cesium Viewer 上完成最常见的人工标注流程：

- 通过 toolbar 选择标注工具。
- 绘制点、线、圆、多边形。
- 进入编辑模式后调整标注几何。
- 进入拖动模式后整体移动标注。
- 通过事件和 API 获取创建、更新、选择、模式变化等结果。

插件应优先保证交互清晰、状态可控、销毁干净，而不是追求 Leaflet-Geoman 的完整功能覆盖。

## 目标用户

- 需要在 Cesium 三维地图上做简单空间标注的业务系统。
- 标注对象数量中等，典型是几十到几百个，不以海量几何编辑为第一目标。
- 使用者需要直观工具栏，不希望直接调用 Cesium 低层事件和 Entity API。

## MVP 功能

### Toolbar

必须提供 6 个核心工具：

- 点: `point`
- 线: `polyline`
- 圆: `circle`
- 多边形: `polygon`
- 编辑: `edit`
- 拖动: `drag`

toolbar 按钮必须互斥。任一时刻最多只有一个 draw/edit/drag mode 处于 active 状态。

### 绘制

必须支持：

- 点: 单击地球表面创建。
- 线: 连续单击添加顶点，至少 2 个顶点才可完成。
- 圆: 第一次点击确定圆心，移动鼠标预览半径，第二次点击完成。
- 多边形: 连续单击添加顶点，至少 3 个顶点才可完成。

绘制中必须支持：

- 线仅根据已点击确认的顶点更新 working geometry，不显示鼠标当前位置相关的临时预览边。
- 多边形绘制阶段使用 Geoman 风格的临时 open polyline；鼠标移动时显示从最后一个已确认顶点到鼠标位置的 hint line，完成后才创建闭合面。
- 圆在第一次点击圆心后，继续支持移动鼠标预览半径。
- 绘制和编辑时支持基础吸附 snapping，可吸附到已有标注顶点和线段；按住 Alt 临时关闭吸附。
- 取消绘制并清理临时对象。
- 完成绘制并触发 `create` 事件。
- 切换工具时自动取消未完成绘制。

### 编辑顶点或控制点

必须支持：

- 点: 拖动点位置。
- 线: 拖动已有顶点。
- 多边形: 拖动已有顶点。
- 圆: 拖动圆心控制点移动中心，拖动半径控制点修改半径。

建议第一版不支持通过中点新增顶点和右键删除顶点，除非业务明确需要。Leaflet-Geoman 支持这些能力，但它们不是当前用户描述的核心诉求。

### 整体拖动

必须支持：

- 点整体拖动。
- 线所有顶点同步平移。
- 圆中心平移，半径不变。
- 多边形所有顶点同步平移。

拖动时必须临时禁用 Cesium 相机交互，避免用户拖动标注时实际旋转或平移相机。

## 非目标

第一版明确不做：

- Leaflet 支持。
- OpenLayers、Mapbox、MapLibre、高德、百度等其他地图引擎适配。
- 裁剪 cut。
- 旋转 rotate。
- 删除模式 removal toolbar。
- 矩形 rectangle。
- 文本 text。
- CircleMarker 概念。
- 多孔 polygon。
- MultiPolygon / MultiLineString。
- 自相交校验。
- 面积、距离、半径测量展示。
- 撤销重做。
- 批量选择和批量编辑。
- 协同编辑。
- 服务端存储。
- 复杂样式面板。
- 2D / Columbus View 完整兼容。

## 推荐默认决策

- 场景模式: 先保证 Cesium 3D scene。
- 地形: 支持贴地为目标，但第一版要允许在 pick 失败时 no-op，不做强行插值。
- 图形承载: 使用 Cesium Entity API。
- 圆: 使用 `ellipse`，`semiMajorAxis === semiMinorAxis`。
- 线: 使用 `polyline`。
- 面: 使用 `polygon`。
- 点: 使用 `point`，可选支持 `billboard` 样式。
- 编辑手柄: 使用独立 helper entities，不写入业务标注集合。

## 需要业务确认的可选项

这些点不阻塞 MVP，但实现前最好明确：

- 圆是否必须允许改半径。本文档建议默认允许，可配置关闭。
- 线/多边形是否需要新增顶点、删除顶点。本文档建议第一版只移动已有顶点。
- 标注是否必须贴地到 terrain / 3D Tiles。本文档建议支持 terrain 拾取，3D Tiles 拾取作为增强项。
- 标注数据最终要导出为 GeoJSON、业务 JSON，还是 Cesium Entity。
- edit mode 采用 Leaflet-Geoman 风格的全局编辑：进入后显示所有可编辑标注的顶点 handles。
